# 元知己 V1.5 最终整合说明

本版是在 V1.4 站点基础上整理出的最终源码版。重点不是再做一个孤立数字人 Demo，而是把数字人放回完整网页流程里：首页认识项目，数字人页陪伴，语音页承接音色，我的空间管理形象和装扮，API 页面负责配置。

## 先说结论

- 当前正式保留 7 个形象：元安、元晴、元熙、元澈、虹色Mao、元元熊猫、元初。
- 原水滴形象相关入口、商品、按钮、CSS 形象和大屏特效已先删除，后面等素材和定位稳定后再单独重做。
- 默认首个形象是元安；首页展示图保留元初静态形象；首页首屏视频已恢复，但不再使用女性 poster。
- 角色选择统一写入 `neuromate-avatar-mode-v15`，陪伴页、语音页、大屏预览、我的空间都读同一个选择。
- 装扮目前先全部免费，元熙保留小舟皮肤、爱丽丝皮肤两个 3D 装扮位。
- 前台不再展示具体同学姓名，角色来源统一改成模型类型或素材类型。
- 旧的 V1.3 / V1.4 README 只作为历史存档，最终验收以本文件为准。

## 本次整理过的主要页面

1. `index.html`
   - 恢复首页 `assets/home-hero.mp4` 视频。
   - 去掉 hero poster，避免首屏出现旧静态女性图。
   - 首页数字人展示区使用元初静态图。
   - 关闭页面淡出跳转，减轻切页时的纸片感和卡顿。

2. `companion.html`
   - 数字人直接内嵌在主舞台，不再用 iframe 嵌套孤立工作台。
   - 形象切换保留 7 个角色。
   - 舞台尺寸加大，Live2D / VRM / 视频 / 静态兜底统一由 `companion-renderer.js` 接管。
   - 增加加载动画；模型加载失败时显示元初兜底，不留空框。
   - 操作入口保留：开始聊天、语音模式、API 配置、大屏预览。

3. `voice-chat.html`
   - 语音页读取当前角色，状态文案、气泡头像、音色预设一起同步。
   - 页面顶部增加角色切换和 API 配置入口。

4. `space.html`
   - 我的空间增加角色切换。
   - 角色预览改成同步角色卡，不再所有角色都显示同一张兜底图。
   - 装扮区目前全部免费；换装会同步回数字人页。

5. `integrations/digital-human-demo/index.html`
   - 作为大屏预览窗口保留。
   - 顶部导航、左上角返回、右上角登录信息与主站同步。
   - 默认读取全站当前角色；在大屏切换角色后，也会同步回主站。
   - 删除原水滴形象特效，保留安静陪伴、本地记忆、状态口型和 API 配置。
