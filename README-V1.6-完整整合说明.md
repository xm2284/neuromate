# 元知己 V1.6 完整整合说明

本版是在 V1.5 完整整合基础上的演示稳定版。重点是把完成度高的数字人、离线可展示能力、开发配置页、本地 Agent 接口和主题视觉统一放到一套可现场演示的流程里：首页认识项目，数字人页陪伴，语音页承接音色，我的空间管理形象和装扮，API 页面作为开发/评审配置入口保留。

## 先说结论

- 当前正式保留 7 个形象：元安、元晴、元澈、虹色Mao、元元熊猫、元瑶、元初。
- 默认首个形象是元安 Live2D；元瑶静态换装形象排在元初前，作为离线和低性能设备的高稳定展示方案。
- 角色选择统一写入 `neuromate-avatar-mode-v16`，并兼容读取旧版 `neuromate-avatar-mode-v15`。
- 元瑶保留静态皮肤换装；其他不支持的角色会禁用装扮并说明原因。
- API 配置页保留，未配置 API 时走本地演示回复；本地服务器提供 `/api/chat` 与 `/api/agent-cluster/analyze`，断网也能完成主要演示流程。
- 雨天场景保留，但雨丝密度和音量已下调，避免遮挡人物。
- Live2D 示例目录中的少量 mp3 是历史示例动作音效占位，不作为核心语音能力验收项。
- 旧的 V1.3 / V1.4 / V1.5 README 只作为历史存档，最终验收以本文件为准。

## 本次整理过的主要页面

1. `index.html`
   - 恢复首页 `assets/home-hero.mp4` 视频。
- 去掉 hero poster，避免首屏出现旧静态女性图。
   - 首页第二屏优先展示元瑶静态形象，元初作为兜底保留。
   - 关闭页面淡出跳转，减轻切页时的纸片感和卡顿。

2. `companion.html`
   - 数字人直接内嵌在主舞台，不再用 iframe 嵌套孤立工作台。
   - 形象切换保留 7 个角色。
   - 舞台尺寸加大，Live2D / 视频 / 静态兜底统一由 `companion-renderer.js` 接管。
   - 增加加载动画；模型加载失败时显示元初兜底，不留空框。
   - 学生主操作保留：开始聊天、语音模式、大屏预览；API 配置只作为开发/评审页保留。
   - Agent 页交接到陪伴页时会显示结构化上下文，不再中断形象渲染。
   - 环境场景支持白天、黑夜、雨天；雨天效果偏轻，优先保证人物清晰。

3. `voice-chat.html`
   - 语音页读取当前角色，状态文案、气泡头像、音色预设一起同步，并显示浏览器实际使用的中文音色。
   - 页面顶部保留角色切换，学生端不再显示 API 配置入口。

4. `space.html`
   - 我的空间增加角色切换。
   - 角色预览改成同步角色卡，不再所有角色都显示同一张兜底图。
   - 装扮区按真实支持范围启用，未拥有装扮会走星贝解锁；不支持的装扮会灰掉并说明原因。
   - 送礼物、签到、抽卡、聊天入口已做前端可点击验证。
   - 页面内突兀英文模板小标题已改成中文。

5. `integrations/digital-human-demo/index.html`
   - 作为大屏预览窗口保留。
   - 顶部导航、左上角返回、右上角登录信息与主站同步。
   - 默认读取全站当前角色；在大屏切换角色后，也会同步回主站。
   - 删除原水滴形象特效，保留安静陪伴、本地记忆、状态口型和 API 配置。

6. `_local-server.js`
   - 保留静态资源服务。
   - 提供 `/api/chat` 本地回复接口。
   - 提供 `/api/agent-cluster/analyze` 本地 Agent mock 接口，前端不再依赖 404 fallback。
